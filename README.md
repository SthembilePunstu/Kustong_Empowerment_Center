 # Khutsong Empowerment Centre Website

A responsive website developed for Khutsong Empowerment Centre as part of our NPO website development project.

## About the Organisation

Khutsong Empowerment Centre is an NPO founded in 2021 with a focus on primary prevention initiatives for gender-based violence (GBV), community education, counselling and referrals, awareness campaigns, and stakeholder engagement.

## Project Goal

The goal of this project is to create a professional, accessible and responsive website that allows visitors to:

- Learn about Khutsong Empowerment Centre
- Understand its programmes and initiatives
- Find information about getting help
- Learn about awareness campaigns and events
- Get involved with the organisation
- Contact the organisation

## Main Website Sections

- Home
- About Us
- What We Do
- Get Help
- Campaigns & Events
- Get Involved
- Contact Us
